# Reliance Smart Retail Data Analysis

## Project Overview
This project explores retail data using Python to identify trends, patterns and insights related to customers, products, stores and retail operations.

This is an independent data analysis portfolio project using a publicly available project dataset. It is not official internal Reliance Retail data.

## Business Objectives
- Explore retail datasets.
- Clean and prepare data for analysis.
- Analyse customer and product data.
- Identify patterns and trends.
- Create data visualizations.
- Generate data-driven business recommendations.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
